# Asset provenance

- `RaceBike.qml`: project-authored vector drawing, distributed under the repository’s MIT license.
- `preview.png` and `screenshots/*.png`: native captures of this plugin, generated
  with `demo/run` from `demo/fixtures/example.json`. Race names, participants and
  results in the fixtures are fictional. No live account or PCS result data is pictured.
- Screenshot colors and typography come from the installed Omarchy theme. Theme
  files, wallpapers and font files are not included in the repository.
- Test HTML is synthetic. Third-party archived HTML used for manual selector
  research is not distributed. The Python adapter uses the standard library only.
- CI uses GitHub-maintained actions pinned to full commits. Omarchy and Qt are
  external runtime dependencies, not bundled copies.

The plugin is unofficial and does not use a PCS logo. The owner must review the
marketplace’s code and preview-asset permission attestation before submission.
