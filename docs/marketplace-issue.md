### Maintainer notes

Version 0.8.1. Unofficial road-cycling dashboard with live race situations, rider gaps, events, finished results/GC and a detachable desktop window. Requires Omarchy 4 Quattro, Python 3 standard library and xdg-utils. Reads public PCS HTTPS HTML with bounded, serialized requests, visible rejection warnings and cooldowns; no account, API key or challenge bypass. Optional native event notifications. Settings use the shell widget-entry API after user changes. The Python adapter and browser/notification commands use argument arrays; package installation in .github/workflows/test.yml is confined to the GitHub Actions runner. Screenshots and test pages use committed fictional fixtures. No separate daemon. 98 behavioral tests pass locally and in GitHub Actions. Native popup, window and installation lifecycle checks are documented in docs/validation.md. See README, docs/data-access.md and docs/assets.md for dependencies, limitations, permissions and provenance.
