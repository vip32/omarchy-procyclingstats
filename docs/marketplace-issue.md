### Maintainer notes

Draft only: the repository URL above is proposed and has not been published. Owner attestations are pending.

Unofficial road-cycling dashboard. Requires Omarchy 4 Quattro, Python 3 standard library and xdg-utils. Reads public PCS HTTPS HTML with bounded requests and visible rejection warnings. Optional native event notifications. Screenshots use fictional committed fixtures. No account, API key or separate daemon. See README, docs/data-access.md and docs/assets.md for permissions and provenance.
